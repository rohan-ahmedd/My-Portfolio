# My-Portfolio

## Project Description
This is a personal portfolio website designed to showcase my academic journey, technical skills, and practical projects. As a Cyber Security student, I built this platform from scratch to strengthen my foundational knowledge of software architecture and web development. It serves as a centralized hub for my professional identity, detailing my educational background, core competencies, and hands-on projects.

## Technologies Used
* HTML5
* CSS3

## Website Features
* **Clean & Responsive UI:** Designed to be accessible and visually appealing across different devices.
* **Intuitive Navigation:** Smooth scrolling navigation for quick access to different sections (About, Skills, Education, Projects).
* **Project Showcase:** A dedicated grid layout highlighting key technical projects, descriptions, and associated tech stacks.
* **Contact Interface:** A structured contact section featuring direct communication details and a messaging form.

## Project Structure
* `index.html` — The main HTML document containing the website's structure and content.
* `style.css` — The stylesheet handling all visual design, layout, and styling.
* `images/` — Directory containing all graphical assets, including profile pictures and project thumbnails.
* `screenshots/` — Directory containing preview images of the final website interface.
* `Report.pdf` — Comprehensive project documentation and report.

## Instructions for Running the Website
1. Clone this repository or download it as a ZIP file to your local machine.
2. Extract the downloaded files into a single folder.
3. Ensure `index.html`, `style.css`, and the `images` folder remain together in the same root directory.
4. Open the `index.html` file in any modern web browser (Chrome, Edge, Firefox, etc.). No local server setup or additional software is required.
